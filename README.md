# 三陸おのや｜わが家のお魚ごはん

「三陸おのや 海のごちそう頒布会」向けのPlayable広告用ミニゲームです。

魚料理の下ごしらえ、骨抜き、味付け、火加減、盛り付けを体験し、完成後に商品LPへ遷移します。

## Preview

https://ichinose-pixel.github.io/onoya-home-kitchen/

## Structure

- `index.html` — game markup
- `style.css` / `polish.css` — visual design and motion
- `game.js` — gameplay and input handling
- `assets/` — optimized game artwork
